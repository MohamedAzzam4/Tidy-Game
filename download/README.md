# Cozy Corner — deliverables

The game itself is the repository at the workspace root (`/home/z/my-project/`):
run `npm install && npm run dev` there and open the preview (dev server on
port 3000).

In this folder you'll find two rendered moments from the verified playthrough:

- `screenshot-initial.png` — the room right after the move: 12 belongings
  spilled around the open box.
- `screenshot-complete.png` — the same room after the verified full
  playthrough: `12 / 12`, "Home, at last."

See the repository `README.md` for setup commands, architecture and the
exact file to edit to change the room (`src/level/house.level.ts`).
