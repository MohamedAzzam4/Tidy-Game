## Behavior this ticket owns

The celebration when a collection completes: a **short animation anchored at the
completed tier** (`collectionStatus().tierId`) and a **soft chime** — both fire
only on incomplete→complete transitions delivered by the model on committed changes
(§8.4 Q2 rules). Breaking a collection is silent (status simply updates). An **exact
put-back** or a **cancel-restore** never produces a transition — the model's
`collectionCompleted` stays empty — so no re-celebration is possible from either
path; the view's restore path routes through the same commit-consumer as normal
drops (C-17, replacing today's restore path that reads only `res.ok`). Mute
suppresses the chime through the existing audio gate (`audio.play` already checks
`muted`).

## Interfaces / data contracts

- `audio.play('collection')` added to the `Sfx` union; warm two-note chime, quieter
  than the existing `complete` arpeggio.
- Feedback consumes **only** commit-time data (`collectionCompleted`) — never
  drag-time state. This preserves the no-hint guarantee.
- Animation is per-tier, self-clears; concurrent completions stagger by ~250 ms.
- **e2e observability (C-14)**: `__cozy.lastSfx` — a read-only, append-only,
  length-capped log of `{ sfx, muted, at }` — joins the debug hook here so CC-016
  can assert the chime path + mute gate in headless Chromium. No state mutation.

## Dependencies

CC-007 only.

## Acceptance criteria

- Chime does not play while muted; toggle state respected on every path.
- One animation per transition; nothing plays when a collection breaks, on mixed
  shelves, on an exact put-back, or on a cancel-restore (named tests:
  `put-back-after-pickup does not re-celebrate`, `cancel-restore does not
  celebrate`, `break-then-regroup celebrates once` — CC-007/CC-009).
- Drag previews unaffected — no coupling introduced between preview and feedback
  paths.
- `__cozy.lastSfx` exists, is read-only, and records recent `play()` calls
  (length-capped) with their mute state.

headless runs — the mute *gate* (no errors, `aria-pressed` state, code path) is.
