## Behavior this ticket owns

Rebuilds the bookshelf (audit found boards at z ≈ 0.68 / 1.3 / top 2.2 with only one
interactive tier carrying 3 slots):

- **4 organized tiers**, board top z ≈ 0.10 / 0.68 / 1.28 / 1.88, decorative top slab
  ≈ 2.42 (room wall height 2.9 allows it); rebuilt tier boards and slab are pinned
  **0.05 thick** (today's drawn shelf-board thickness; the bottom panel stays 0.10
  thick as drawn), so per-tier `clearance` = underside of the next board − topZ is
  **0.53 / 0.55 / 0.55 / 0.49** (top tier: slab underside 2.37 − 1.88) — every
  clearance ≥ tallest upright book (0.36) + 0.10 margin so each upright book variant
  fits on every tier.
- **16 slot anchors** (4 per tier, ids `bs-t{1..4}-s{1..4}`, ≥ 0.30 spacing along y)
  — 12 needed by the collections, 4 spare; any tier may host any collection (D2
  revision). The corrected 0.20-wide upright book keeps a 0.10 gap to the 0.30
  spacing (capacity unaffected, C-3).
- **Tier SurfaceDef entries** with per-tier `clearance` = next board underside −
  topZ, plus `data-surface` tags so CC-005's hit-testing resolves tier intent;
  books dropped on the tier surface (not in slots) are **upright** (orientation
  rule, plan §8.1/C-9).
- **Merged, support-relative depth-sorted paint list (C-6)**: this ticket ships the
  merged furniture+items paint list behind the existing `depth()` abstraction —
  items resting on the shelf key `depth(shelf) + ε` so the shelf never paints over
  the books standing on it; floor items keep the plain `x + y` key. No new layer,
  no engine.
- **Decoy cleanup**: the audit found non-interactive static books painted *inside* the
  current asset on the interactive tier (teal/mustard/terracotta) plus a small stack.
  They move to the non-interactive bottom cubby or are removed — never on an
  interactive tier, or cleanliness feedback becomes nonsense.

- 16 unique slot ids; tier surfaces registered and tagged `data-surface`.
- Upright books render standing on all four tiers with correct painter order vs

  insurance.
- Level sanity tests extended: slot count ≥ 12 books, tier bounds contain their
  slots, clearance > max book height (0.36) + 0.10 margin on every tier.
