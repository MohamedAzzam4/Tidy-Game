## Interfaces / data contracts

```ts
interface SurfaceDef {
  id: string;
  furnitureId?: string;          // which furniture provides it (absent for floor)
  kind: 'floor' | 'furniture';
  bounds: { minX: number; maxX: number; minY: number; maxY: number }; // room units
  topZ: number;                  // top face of the drawn placement surface (the walkable height)
  clearance?: number;            // free height above; default = room.wallHeight − topZ;
                                 // pinned explicitly when art sits above (A9)
}

interface ItemFootprint { dx: number; dy: number; height: number } // ground AABB + upright height
// dx/dy = full ground extent of the drawn base layer, centered on the anchor (C-3/Q3 convention)

type ItemOrientation = 'flat' | 'upright';
type ItemFootprintTable = { [asset: string]: { [o in ItemOrientation]?: ItemFootprint } };
type FurnitureFootprintTable = { [furnitureId: string]: ItemFootprint };  // floor-exclusion AABBs

interface CollectionDef { id: string; label: string; colorKey: 'red' | 'green' | 'blue' }

// ItemDef gains:  collectionId?: string
// LevelDef gains: surfaces?: SurfaceDef[]; collections?: CollectionDef[]
//   (no seed field — the game instance owns the live seed and `?seed=`; A3/CC-013)

type DropTarget =
  | { type: 'slot';    slotId: string }
  | { type: 'surface'; surfaceId: string; x: number; y: number };
```

The revised `DropResult`/`PickupResult` shapes live in `model.ts`/`types.ts` and are
CC-004's file scope (ok-branch `target: DropTarget`, `PickupResult.from` widened to
any non-held location — plan §8.1).

Invariant: everything stays in room coordinates (origin = back corner, +x right wall,
+y left wall, z up). No screen-space values in data — this is what keeps a later
camera change possible.
